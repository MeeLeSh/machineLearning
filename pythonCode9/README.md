# Поиск аномалий: LOF и Isolation Forest

Две самостоятельные работы по теме «Обнаружение аномалий»: учебное задание на данных `diy.txt`
и самостоятельная работа на данных `banks.txt`. Всё оформлено в виде исполненных Jupyter-ноутбуков
(с сохранёнными выводами и графиками), библиотека — `scikit-learn`.

## Состав папки

| Файл | Что это |
|---|---|
| `01_diy_lof_isolation_forest.ipynb` | Учебная часть: `diy.txt`, только **Частота** (`Frequency`) и **Сумма** (`Monetary_A`), только клиенты с `Frequency > 1`. LOF, Isolation Forest, сравнение методов, проверка роли фильтра по частоте. |
| `02_banks_lof_isolation_forest.ipynb` | Самостоятельная часть: `banks.txt`, пункты 1–6 задания (LOF `novelty=False` → число аномалий → фильтрация → LOF `novelty=True` → прогон отфильтрованных аномалий → Isolation Forest → метрики качества). |
| `data/diy.txt`, `data/banks.txt` | Исходные данные (копии файлов из задания). `banks.txt` — в кодировке `cp1251`. |
| `.venv/` | Готовое окружение с `scikit-learn`, `pandas`, `matplotlib` (≈ 470 МБ, можно удалить, если ставите пакеты сами). |

## Главные результаты

**`diy.txt`** (29 887 клиентов с `Frequency > 1`):

* LOF с настройками по умолчанию — **75 аномалий (0,25 %)**, порог `LOF > 1,5`;
* Isolation Forest с настройками по умолчанию — **4 413 аномалий (14,8 %)**, порог `score < −0,5`;
* пересечение — 46 объектов (Jaccard ≈ 0,01); при одинаковой доле аномалий IF находит 75 объектов, из них 13 совпадают с LOF;
* без фильтра `Frequency > 1` LOF даёт 1 346 «аномалий», из них 94,5 % — клиенты с одним визитом.

**`banks.txt`** (371 банк):

| Пункт | Результат |
|---|---|
| п.1–2. LOF `novelty=False`, по умолчанию | **77 аномалий (20,8 %)**; `LOF > 2` — 36, `LOF > 5` — 8 |
| п.3. LOF `novelty=True` на 294 «нормальных» банках | модель нормы; внутри очищенных данных 21 «пограничный» банк |
| п.4. Прогон 77 отфильтрованных аномалий | **76 из 77 совпадений (98,7 %)**; не подтвердился «Камский коммерческий банк» (LOF 1,591) |
| п.5. Isolation Forest, по умолчанию | **30 аномалий (8,1 %)**, 26 совпали с LOF; при `contamination` = доля LOF — 77 аномалий, 41 совпадение |
| п.6. Метрики | Precision, Recall, F1, ROC-AUC, PR-AUC/AP, MCC (демо на синтетике с разметкой) + Jaccard, Cohen's κ, silhouette, precision@K, bootstrap-устойчивость для данных без разметки |

Содержательно в аномалии попадают: банки-гиганты (Сбербанк, ВТБ, Газпромбанк…), все 9 банков
с отрицательным капиталом («Траст» — LOF 4462) и банки с «ломаными» пропорциями (нулевые средства
физлиц при крупных активах).

## Примечания по методике

* Перед LOF признаки стандартизуются (`StandardScaler`): у них разный масштаб, а метод основан на расстояниях.
  В ноутбуке по банкам есть отдельный раздел о чувствительности результата к преобразованию (56 / 77 / 47 аномалий).
* «Настройки по умолчанию» относятся к параметрам алгоритма (`n_neighbors=20`, `contamination='auto'`,
  `n_estimators=100`) — preprocessing при этом остаётся стандартным.
* В режиме `novelty=True` масштабирование переобучается на очищенных данных, чтобы не занести убранные
  выбросы в среднее и отклонение.
